NoMusic

Replace Apple Music with Spotify for your media keys.

When you press Play/Pause without an audio app open, macOS opens Apple Music automatically. NoMusic intercepts that and opens Spotify instead.

This installer will:

  • Install the NoMusic background service
  • Configure it to start automatically at login for every user on this Mac
  • Install "NoMusic Uninstaller" in your Applications folder

Requirement: Spotify must be installed.
